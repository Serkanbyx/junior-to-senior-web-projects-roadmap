## Tips

- **Don't rush.** A level is done when you could rebuild any project in it without a guide.
- **Ship every project.** Each one gets its own repo and a live deployment.
- **Write the README.** Technical communication matters as much as the code.
- **Start where it's uncomfortable.** Repeating easy projects doesn't build new skills.
