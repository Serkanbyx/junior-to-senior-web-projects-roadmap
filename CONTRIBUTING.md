# Contributing

This roadmap is meant to grow with the community. Contributions are welcome.

## Ways to contribute

- **Add a build guide.** Pick a project that still links to `#` and write its guide.
- **Improve an existing guide.** Fix mistakes, clarify steps, add a better tip.
- **Suggest a project.** Propose a new project for a level, with a short justification of the skill it teaches.
- **Fix the README.** Broken links, typos, formatting.

## Adding a project guide

1. Fork the repository and create a branch.
2. Copy [`docs/TEMPLATE.md`](./docs/TEMPLATE.md) into the correct `docs/level-N/` folder, named in `kebab-case.md`.
3. Fill in every section. Keep build steps as numbered prose — explain the *how* and *why*, don't paste full solutions.
4. Update the matching row in `README.md` so the **Guide** link points to your file.
5. Open a pull request describing what you added.

## Style

- Guides are concise — roughly one screen of reading.
- Write in plain English. Assume the reader knows the previous level.
- Prefer reasoning over code. The reader should be able to build the project themselves.

## Code of conduct

Be respectful and constructive in issues and reviews. Assume good intent.
